# 4. 工具调用

## 学习目标

模型负责决定要不要用工具，程序负责真正执行。

完成标准：错误参数不会执行；工具结果会回到下一轮模型输入。

### 4.1 什么时候该用工具

**要点**

- 该用工具：需要准确的计算、当前时间、查询外部系统、写入外部系统。
- 不必用工具：润色、总结已经在上下文里的文字、开放式讨论。
- 模型决定叫不叫、叫哪一个。执行发生在你的程序里。
- 要求精确的数不要交给模型心算。

**练习**

把下面 6 个问题分成「必须用工具」或「不必用工具」，并各写一句理由：现在几点；把这段话改得更短；23.5 乘以 18；根据上面三段总结要点；北京明天天气；给这个函数起个名字。

**自检**

- [ ] 时间和精确乘法分在必须用工具
- [ ] 改写、总结、起名分在不必用工具
- [ ] 每条都有一句理由，理由写的是「要不要执行外部动作」

### 4.2 工具描述、参数与回填

**要点**

- 每个工具写清四件事：名字、何时使用、参数名和类型、不该用来做什么。
- 参数尽量少。必填和可选分开写。
- 程序执行完，把结果放回对话，再让模型生成给用户的话。
- 模型下一轮看到的是工具结果。不要在代码里先替模型写好用户答复。

**练习**

为「当前时间」和「四则运算」各写一段工具描述。运算只接受两个数和一个运算符（加、减、乘、除）。

**自检**

- [ ] 只读描述就能知道参数名和类型
- [ ] 运算工具没有第三个多余的必填参数
- [ ] 描述里写了不该用来做什么

<a id="4-3"></a>

### 4.3 失败与越权

**要点**

- 缺必填参数、类型不对、除数为 0：不执行，把错误原因回填给模型。
- 工具超时：回填超时，不要假装拿到了结果。
- 不在允许列表里的工具名直接拒绝。
- 写操作（发邮件、删数据）默认不开放。

**练习**

接上「当前时间」和「四则运算」。用对话确认：问时间会走到时间工具，问乘法会走到运算工具，回复中的数字等于程序算出的结果。再发一个缺参数或除以 0 的调用，确认程序没有执行运算。

**自检**

- [ ] 时间问题走到了时间工具
- [ ] 乘法走到了运算工具，且数字等于程序结果
- [ ] 错误参数没有执行
- [ ] 工具结果出现在下一轮发给模型的消息里
