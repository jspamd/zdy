# 5. RAG 知识库

## 学习目标

回答以你的文档为准，并带出来源。

完成标准：有答案的问题能指出对应片段；无答案的问题不编造。

## 课时

### 5.1 切分、嵌入与召回

**要点**

- 文档先切成小段，每段单独做成向量。
- 问题也做成向量，按相似度取出最接近的若干段。
- 切太长会掺进无关句；切太碎会把一个事实拆开。先用固定长度，相邻段保留少量重叠。
- 召回得到的是候选片段，不是最终答案。答案仍由模型根据这些片段生成。

**练习**

选一篇你自己的短文，切成 3 到 6 段。给每段写一句摘要。检查有没有把一句话从中间切断，有的话改切分位置后再留一版。

**自检**

- [ ] 没有任何一段同时塞进两个互不相关的主题
- [ ] 能指出原本被切断的句子，以及改完后的切分位置
- [ ] 能说明召回片段和最终答案不是同一步

### 5.2 提问改写、Top-K 与引用

**要点**

- 用户问题里有「这个」「上面说的」时，先改写成不看上文也能检索的句子，再去召回。
- Top-K 先取小，例如 3。段太少会漏掉依据，段太多会把无关句一起送进提示。
- 放进提示的是原文片段和来源编号，不是你事先写好的结论。
- 要求回答带上来源编号，这样你能核对它用了哪一段。

**练习**

写 2 个必须看上文才能懂的问题，再各改写成可以单独拿去检索的句子。选定你的 K，并用一句话说明 K 变大时会发生什么。

**自检**

- [ ] 改写后的句子里没有「这个」「上面」
- [ ] 写明了 K 的数值
- [ ] 能说明 K 变大时上下文变长、无关片段变多

### 5.3 答不出就拒答

**要点**

- 在提示里写明：片段不够就回答不知道，并说明缺的是哪类信息。
- 不知道时，不要用常识补上文档里没有的数字、日期、人名。
- 检索结果为空，和检索到了段落但不包含答案，都要拒答。

**练习**

准备 3 篇短文档并放进检索。提 5 个问题：3 个能在文档里找到答案，2 个文档里没有答案。有答案的要指出片段，没答案的必须拒答并说明缺什么。

**自检**

- [ ] 3 个有答案的问题各自指出了对应片段
- [ ] 2 个无答案的问题明确说不知道
- [ ] 拒答里没有编造文档中不存在的事实

- [x] 未开始
- [ ] 进行中
- [ ] 已完成
